# Инфраструктура при нулевом бюджете

Стек: Python + FastAPI, БД — Neon (Postgres + pgvector), сайт — Vercel Hobby, воркер —
GitHub Actions, ежечасный триггер — cron-job.org. Все сервисы на бесплатных тарифах, без карты.

## Итоговая схема

```
cron-job.org, каждый час в :05
   └─ GET /api/cron, Authorization: Bearer CRON_SECRET ──> Vercel (FastAPI)
Vercel ── POST /actions/workflows/worker.yml/dispatches (GITHUB_DISPATCH_TOKEN) ──> GitHub Actions
GitHub Actions (concurrency: worker)
   └─ python -m app.worker run → recheck → summarize → media → embeddings → letsplays
        ├─ backend.metacritic.com          (карточки, оценки, отзывы)
        ├─ Groq / Gemini                   (резюме, летсплеи, эмбеддинги)
        ├─ YouTube Data API, yt-dlp, Steam (летсплеи, трейлеры, скриншоты)
        └─ Neon Postgres                   (games, runs, run_items, ...)
Vercel (FastAPI + Jinja2)
   ├─ список, карточка, фильтр, поиск, сортировка, похожие игры  ── читает Neon
   ├─ /monitor: опрос /api/status каждые 2,5 с                     ── читает runs / run_items
   ├─ «Запустить сейчас»: POST /api/run → workflow_dispatch
   └─ /api/telegram/webhook: бот, /start → кнопка Mini App
```

**Почему воркер в GitHub Actions, а не в Vercel:**
- нет лимита 300 с на функцию (job — до 6 часов), можно ждать rate-limit LLM и ставить
  тяжёлые зависимости (yt-dlp);
- для публичного репозитория минуты Actions бесплатны и не ограничены;
- от параллельных прогонов защищает `concurrency: worker` в workflow; дополнительно
  `/api/cron` и воркер пропускают автоматический запуск, если прогон ещё идёт или
  автоматический уже был за последние 50 минут (`queries.auto_run_blocker`).

## Ежечасный запуск: cron-job.org

`schedule` в GitHub Actions оказался ненадёжным: после включения `cron: "17 * * * *"`
(2026-10-15) за 2,5 часа не было ни одного запуска, за первые сутки — один, с опозданием на
20 минут. Поэтому встроенный `schedule` убран, а запуск внешний: cron-job.org в :05 дёргает
`/api/cron` на сайте, сайт вызывает `workflow_dispatch`.

- PAT (fine-grained, только этот репозиторий, Actions: read & write) хранится только в Vercel.
  cron-job.org знает лишь `CRON_SECRET`, которым можно только запустить прогон.
- Ручной запуск (кнопка на `/monitor` или `workflow_dispatch` в GitHub) проверкой 50 минут не
  ограничен, но не стартует, пока идёт другой прогон.

## Vercel Hobby

| Что | Лимит | Значение для нас |
|---|---|---|
| FastAPI | Поддерживается нативно (`app/main.py`) | Сайт и API — одна Python-функция |
| Длительность функции | 300 с | Воркер сюда не помещается — он в Actions |
| Cron | Раз в сутки, точность ±59 мин | Для ежечасного запуска не годится — cron-job.org |
| Active CPU / память / вызовы | 4 CPU-ч / 360 ГБ-ч / 1 млн в месяц | Хватает с запасом |
| Логи | 1 час | История прогонов хранится в своей БД |
| Использование | Только некоммерческое | Тестовое задание подходит |

При превышении лимитов Hobby фича блокируется до конца 30-дневного окна; денег не списывают.
Новый проект по умолчанию закрыт Vercel Authentication — для сайта она отключена
(Project Settings → Deployment Protection).

## Neon Free

- 1 ГБ на проект, 100 CU-часов в месяц, карта не нужна. Расширение `vector` (pgvector) для
  эмбеддингов доступно на бесплатном тарифе.
- Scale-to-zero через 5 минут простоя, холодный старт ~0,5–1 с.
- CU-часы — реальное ограничение (БД без сна съела бы ~182 CU-ч в месяц), поэтому: никаких
  uptime-мониторов на эндпоинты с БД, прогон воркера короткий, страница мониторинга
  опрашивает статус, только пока открыта.

## LLM

**Резюме отзывов: Groq `openai/gpt-oss-120b` с `reasoning_effort: low`, фолбэк — Gemini
`gemini-flash-lite-latest`.** Одно обращение на игру, JSON с двумя резюме (критики и игроки).
Замер на Elden Ring (13 рецензий + 21 отзыв игроков): ~3000 токенов на входе, ~350 на выходе,
2 с. Резюме пересчитываются только при изменении набора отзывов (хэш), поэтому реальная
нагрузка — десятки вызовов в день.

| Провайдер | Модель | Лимиты free | Роль |
|---|---|---|---|
| Groq | `openai/gpt-oss-120b` | 30 RPM, 1K RPD, 8K TPM, 200K TPD | Резюме: ~2 в минуту, ~60 в день |
| Gemini | `gemini-flash-lite-latest` → `gemini-flash-latest` | Хватает на сотни запросов в день | Фолбэк резюме, летсплеи |
| Gemini | `gemini-embedding-2` (768 измерений) | Пакеты по 100; есть суточная квота на проект. При минутном 429 ждём `retryDelay`, при суточном — откладываем до следующего прогона | Эмбеддинги описаний для похожих игр |

При 429 с коротким Retry-After клиент ждёт и повторяет, с длинным (суточный лимит) —
переключается на следующего провайдера. GitHub Models (`models.github.ai`) проверен и не
годится: на любой запрос отвечает `200 text/plain "OK"` вместо ответа модели.

## Летсплеи (доп. часть 1)

- **Поиск:** YouTube Data API, `search.list` с `order=viewCount`, затем `videos.list`
  (длительность, просмотры, язык). У `search.list` своя квота — 100 запросов в сутки на проект,
  поэтому ищем один раз на игру, только для игр с оценками, по 3 игры в час. Отбор: название
  игры целым словом в заголовке, не трейлер/обзор/интервью, английский, 15–180 минут, максимум
  просмотров; Gemini дополнительно подтверждает, что ролик именно про эту игру.
- **Субтитры YouTube из облака недоступны:** и GitHub Actions (Azure), и Vercel (AWS)
  получают «Sign in to confirm you're not a bot». Официальный `captions.download` отдаёт
  субтитры только владельцу ролика. Cookies аккаунта не используем.
- **Схема:** в облаке Gemini смотрит ролик по ссылке YouTube тремя фрагментами — начало 5 мин,
  середина 5 мин, конец 10 мин (~110 тыс. токенов, ~20 с) — и одним запросом пишет пересказ
  речи блогера, вывод, плюсы и минусы и 2–3 дословные цитаты с переводом на русский. Мнение
  блогера разбросано по ролику, а явный итог звучит в конце — три фрагмента ловят и то, и
  другое. При локальном запуске (домашний IP) доступны субтитры: Gemini читает весь текст, а
  полная расшифровка показывается на сайте под спойлером. На Silver Pines вывод по трём
  фрагментам совпал с выводом по полным субтитрам.
- Полную расшифровку видео силами Gemini не делаем: на 20 минутах речи модель выдаёт обрывки
  с повторами или зацикливается.
- Gemini часто отвечает 503 (перегрузка); такие игры перепроверяются через сутки по уже
  найденному ролику, без новой квоты YouTube.

## Проверка доступа из облака (зонд `probe/`)

В начале работы зонд проверил, что Metacritic доступен с облачных IP (2026-10-15).

- **GitHub Actions** ([run 38715625939](https://github.com/NellasTerton/skytec-metacritic/actions/runs/38715625939)),
  egress AS8075 Microsoft: все страницы `www` и эндпоинты backend отдают 200, Cloudflare-челленджей
  нет; 20 параллельных composer-запросов — 20 × 200 за 0,7 с.
- **Vercel** (AS14618 Amazon): то же самое, 20 × 200 за 0,34 с.
- User-Agent важен везде одинаково: `Python-urllib` и `python-requests` получают 403,
  `httpx` с браузерным UA — 200.
